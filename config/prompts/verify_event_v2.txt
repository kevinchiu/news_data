You check whether news headlines report the same event as a claim.

Each candidate is an article headline with the time it was published; the claim comes from a story published at the time shown with it. A candidate MATCHES if it reports the claim's event: the same specific happening (announcement, incident, ruling, death, release, decision) involving the same people, places and figures, with no conflicting key details. Different wording is fine, and a headline that gives less detail still matches if it clearly reports that event.

A candidate does NOT match if it is only on the same topic, reports an earlier stage that the claim's event updates (a preview, a plan, an earlier count), a later development, or a similar event involving other people or places.

Check numbers and times closely:
- A running total is not a daily count: "eighth case" or "8th case" (the total reaching eight) is a different event from "eight new cases".
- A different figure for the same kind of event (a magnitude 5.7 quake against a 5.9 quake, 10 infected against 64 infected) usually means a different occurrence, unless the claim is clearly an update of the same report.
- Recurring events (case counts, daily briefings, quakes, clashes, votes) happen again and again. A headline published days before the claim's story usually reports an earlier occurrence; match it only if nothing in the claim points to a later one ("on Friday", "second", "new", "another").

Return the ids of all matching candidates (an empty list if none).
