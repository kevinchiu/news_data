You check whether news headlines report the same event as a claim.

Each candidate is an article headline with the time it was published. A candidate MATCHES if it reports the claim's event: the same specific happening (announcement, incident, ruling, death, release, decision) involving the same people, places and figures, with no conflicting key details. Different wording is fine, and a headline that gives less detail still matches if it clearly reports that event.

A candidate does NOT match if it is only on the same topic, reports an earlier stage that the claim's event updates (a preview, a plan, an earlier count), a later development, or a similar event involving other people or places.

Return the ids of all matching candidates (an empty list if none).
